# 验证记录：A/B 实验判断的模拟

> 轻量记录：按 [验证标准](../../docs/verification-standard.md) 的十个部分合并为七节。

## 一、待验证结论与实际结果

Python 3.14.8，随机种子 20261002，显著性水平 0.05，两比例 z 检验（双侧）。

1. **A/A 的假阳性**：两组转化率都是 10%、每组 10000 人，4000 次实验中 203 次判为显著，5.1%。
2. **中途偷看**：同样的 A/A，看 5、10、20 次且一显著就停，判为显著的比例是 14.5%、20.2%、24.3%。
3. **样本量与功效**（真实提升 10% → 11%）：公式算出功效 80% 时每组需要 14749 人。每组 2000、10000、14749 人时检出比例为 17.4%、64.1%、80.6%；显著结果里观察到的平均提升为 2.44、1.26、1.12 个百分点（真实值 1.00）。
4. **不显著**：每组 2000 人时 82.8% 的实验不显著，这些实验的 95% 置信区间平均宽 3.8 个百分点；全部实验中置信区间包含真实差值的占 95.0%。
5. **分析单位**：按用户分流的 A/A，把每次访问当独立样本检验时 17.9% 判为显著；按用户检验时 4.6%。
6. **多指标**：A/A 实验同时看 20 个指标，至少一个显著的占 63.9%（理论值 64.2%）；显著性水平除以 20 后为 4.8%。
7. **按天汇总**：真实提升 1 个百分点、每组每天 1000 人、10 天，每天基础转化率在 ±3 个百分点内波动。按用户检验 63.5% 检出；压成每组 10 个日转化率做 t 检验 0.1% 检出。

## 五、误差、限制与不能推出的结论

- 种子固定时输出可逐字复现；换种子或换 Python 版本后数字会在抽样误差内变化（4000 次模拟时，5% 附近的比例标准误差约 0.34 个百分点），断言用的是范围。
- 模拟的是理想条件：独立同分布的用户、稳定的转化率、没有新奇效应与分流故障。真实实验的问题比这里多，不能据此估计某个具体实验的错误率。
- 分析单位一节的假阳性比例取决于假设的访问次数分布与用户间差异（指数分布的访问次数、Beta(0.5, 4.5) 的转化倾向），只说明方向，具体数值不能外推。
- 按天汇总一节的差距来自每天基础转化率的波动；波动越小，两种做法越接近。
- 只覆盖转化率（比例）指标的固定样本量检验；序贯检验、贝叶斯方法、比率型与长尾指标（如人均收入）没有涉及。
