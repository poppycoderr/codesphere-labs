## 一、待验证结论与实际结果

| 场景 | 结果 |
|---|---|
| 起点取 ready / doing | 已完成 4 项的中位周期 36.5h / 13h |
| B 重开 | 按第一次完成 10h，按最后一次完成 18h |
| 每日快照 | B 两天都是 done，看不到日内的重开 |
| 活动与等待 | A 处理占 14%，C 7%，F 50% |
| 只统计已完成项 | 漏掉第 96h 时已等待 95h 的 G 与 86h 的 E；取消的 D 不计入 |
| 按到达顺序处理 C | 晚到的 review 事件让最后状态变成 review |
| 重复事件 | 不去重时 D 有两次 doing |
| 在制工作 | 12h 时 6 项，14h 时 B 重开后 7 项 |

## 五、误差、限制与不能推出的结论

- 数据是手写的 7 个工作项，用来说明口径怎样改变数字；不代表任何团队的真实交付数据，也不评价流程好坏。
- 时间按日历小时计算，没有扣除非工作时间；真实系统要先决定是否按工作日计算。
- 指标只描述工作项的流转，不用于比较个人。
