# 验证记录：折线编辑会话：预览、提交、撤销与外部更新

> 轻量记录：按 [验证标准](../../docs/verification-standard.md) 的十个部分合并为七节。

## 一、待验证结论与实际结果

| 场景 | 结果（两种配置相同） |
|---|---|
| 画布尺寸 | 900px：显示 600px、缓冲 600；390px：显示 358px、缓冲 1200 |
| 拖动中 | 预览 p1 在 (120,110)，正式模型仍在 (80,80)，版本 0 |
| 松开 | 提交一次，版本 1，撤销栈 1 条 |
| 撤销 / 重做 | 回到 (80,80) / 回到 (120,110)，各让版本加一 |
| Esc / 派发 pointercancel | 取消，正式模型不变 |
| 拖到画布左侧之外 | 提交，x 限制为 0 |
| 拖动期间别处更新了模型 | 松开时 stale，不提交 |
| 快照式撤销 | 把别处对 p3 的修改一起撤掉 |
| 命令式撤销 | 只还原 p1，p3 保留；p1 也被别处改过时返回 conflict |

## 五、误差、限制与不能推出的结论

- `pointercancel` 是测试主动派发的，没有模拟移动系统的真实中断；触摸、手写笔与多指操作没有覆盖。
- 页面是原生 Canvas，没有使用 React 或第三方画布库；接入框架时组件卸载、订阅释放等生命周期需要另外验证。
- 「外部更新」由测试直接调用接口模拟，没有实现协同编辑或服务端冲突合并。
