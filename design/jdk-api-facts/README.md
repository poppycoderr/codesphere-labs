# 设计原则与设计模式两篇引用的 JDK 事实

对应文章：[设计原则](https://github.com/poppycoderr/codesphere/blob/master/docs/design/design-principles.md)。另见 [设计模式决策图](https://github.com/poppycoderr/codesphere/blob/master/docs/design/design-patterns.md)。

这是一个**轻量实验**：保留核心代码、一条验证入口、原始输出和简要验证记录，用来复现文章中的关键数字。

## 快速运行

```bash
make verify     # 需要 JDK 21+；约 5 秒
make clean
```

不启动容器，不占用端口。
