# 验证记录：没评分不等于打了零分

> 轻量记录：按 [验证标准](../../docs/verification-standard.md) 的十个部分合并为七节。

## 一、待验证结论与实际结果

Python 3.14.8，随机种子 20261002。36000 个格子里观测到评分 3827 个（10.6%），测试集 821 个，训练集平均分 3.03。

| 预测方法 | 测试集 RMSE |
|---|---:|
| 全部预测为训练集平均分 | 1.18 |
| 预测为用户自己的平均分 | 1.22 |
| 缺失当 0 的近邻加权 | 2.92 |
| 只用已观测评分的近邻加权 | 1.08 |

- 缺失当 0 时，预测值平均 0.41，测试集真实平均 3.07。
- 每人推荐 5 个没评过的物品：缺失当 0 时 57% 来自被评分次数最多的 10 个物品，只用已观测评分时 3%。
- 推荐命中测试集的物品，用户实际打分的平均值：缺失当 0 为 3.15（143 个），只用已观测评分为 3.79（38 个）。

## 五、误差、限制与不能推出的结论

- 数据是合成的，评分由低维潜在向量生成，缺失只与物品的热门程度有关、与评分高低无关。真实数据里用户更倾向于给喜欢的东西评分，缺失本身带有信息，本实验没有模拟。
- 只用已观测评分的近邻方法比猜平均分好 0.10，幅度不大：数据很稀疏，共同评分少。结论是「把缺失当 0 比什么都不做还差」，不是「近邻方法效果好」。
- 推荐命中测试集的样本只有 38 与 143 个，平均分只说明方向。
- 没有比较矩阵分解等其他模型，也没有涉及点击、购买这类隐式反馈。
- 种子固定时输出可逐字复现；断言用的是范围。
