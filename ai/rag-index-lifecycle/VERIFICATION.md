## 一、待验证结论与实际结果

| 场景 | 结果 |
|---|---|
| 7 天改成 15 天后重新导入（只按内容哈希） | 索引 3 块，检索同时返回 15 天与 7 天 |
| 同上（按来源记录块） | 索引 2 块，只返回 15 天 |
| 删除 old-faq.md，朴素索引只增量导入 | 仍返回「旧版：3 天」 |
| 全量同步 | 删除后不再返回 |
| 查询用新模型、文档是旧模型的向量 | 相似度从 0.33 变成 0.11（假嵌入，只说明不可比）；按模型标记拒绝混用 |
| 维度不同的模型混用 | 报错：维度不一致 |
| 员工与人事查同一个问题 | 员工看不到 hr 组的块 |
| 答案缓存只用问题做键 | 员工拿到了人事先前问出的 hr 内容 |
| 缓存键加上权限范围 | 员工得到自己可见的内容 |

## 五、误差、限制与不能推出的结论

- 嵌入是假实现，相似度数值没有语义意义，只用来演示「不同模型的向量不能混用」和排序变化。
- 只覆盖单进程内存索引；向量数据库的批量删除、软删除、版本与过滤语法各不相同，以所用产品的文档为准。
- 权限只做了按组过滤，没有覆盖撤权后的缓存失效时机与多租户隔离。
