# 验证记录：用量记账

> 轻量记录：按 [验证标准](../../docs/verification-standard.md) 的十个部分合并为七节。

## 一、待验证结论与实际结果

| 场景 | 结果 |
|---|---|
| 流式片段与 usage | 12 个片段、43 个字符；输出 31 个 token |
| 客户端中途断开 | 没有 usage 事件；供应商计 12 个 |
| 朴素：超时后重试 | 账本 62，供应商 46 |
| 朴素：usage 重复投递 | 账本 62，供应商 31 |
| 朴素：回退到小模型 | 费用 0.341，供应商 0.091 |
| 幂等入账 + 对账：三种情况 | 输出与费用都与供应商一致 |

## 五、误差、限制与不能推出的结论

- 供应商、价格与 token 数都是虚构的；真实服务是否在流式中返回 usage、超时后能否按响应 ID 查到用量，取决于具体服务的接口。
- 实验在单进程内用 SQLite 主键实现幂等；多实例时要用共享数据库的唯一约束。
