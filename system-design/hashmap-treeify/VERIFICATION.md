# 验证记录：HashMap 冲突链的树化条件与查找代价

> 轻量记录：按 [验证标准](../../docs/verification-standard.md) 的十个部分合并为七节。

## 一、待验证结论与实际结果

| 场景 | 结果 |
|---|---|
| 默认容量的表依次放入冲突的键 | 8 个时仍是链表（表长 16）；第 9 个扩到 32；第 10 个扩到 64；第 11 个转成红黑树 |
| 初始容量 128 的表放入 8 个冲突的键 | 仍是链表 |
| 1000 个冲突、不可比较的键，逐个查找 | equals 共 501499 次，平均 501 次；查不存在的键 1001 次 |
| 同样的键实现 Comparable | equals 共 10405 次，平均 10 次；查不存在的键 18 次 |
| 对照：一直是链表 | 平均 500 次（计算值） |

## 五、误差、限制与不能推出的结论

- 树化的阈值（8、64）与退化阈值（6）是 JDK 的实现细节，不属于 API 规范；实验只验证 JDK 25.0.4.1 的行为。
- 只统计 equals 调用次数，没有测量耗时；可比较的键在树中查找时还会调用 compareTo。
