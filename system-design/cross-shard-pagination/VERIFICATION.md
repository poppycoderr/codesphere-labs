# 验证记录：跨分片分页：归并代价、单列游标与复合游标

> 轻量记录：按 [验证标准](../../docs/verification-standard.md) 的十个部分合并为七节。

## 一、待验证结论与实际结果

| 场景 | 结果 |
|---|---|
| offset 第 1 / 50 / 500 页 | 共读取 80 / 4000 / 20000 行，结果正确 |
| 把 offset 平均分给各分片 | 第 50 页只有 5 / 20 行正确 |
| 单列游标 `created_at <` | 遍历 15978 行，遗漏 4022 行 |
| 单列游标 `created_at <=`（排除自身） | 在同值的行之间反复翻页，遗漏 17195 行、重复 37215 行后被实验停止 |
| 复合游标 `(created_at, id) <` | 20000 行，不漏不重，与全局排序逐行一致 |
| 全量遍历的读取量 | 复合游标 79865 行；offset 17510000 行 |
| 翻页期间插入一条更新的数据 | offset 的第 2 页第一行重复上一页最后一行；复合游标不受影响 |

## 五、误差、限制与不能推出的结论

- 纯内存模拟，读取量以「各分片返回的行数」计，没有网络与排序的实际耗时；真实数据库中还取决于索引是否覆盖排序列与游标条件。
- 每页的归并只需要各分片的前 limit 行，这依赖各分片按同样的键有序返回。
- 复合游标的决胜键必须全局唯一；分片内自增 id 在分片之间可能重复，需要用全局唯一的 id 或 (分片号, id)。
