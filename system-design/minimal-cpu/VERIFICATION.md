# 验证记录：一台最小的累加器 CPU

> 轻量记录：按 [验证标准](../../docs/verification-standard.md) 的十个部分合并为七节。

## 一、待验证结论与实际结果

| 场景 | 结果 |
|---|---|
| 6 × 7 循环加法 | 输出 42，61 步停机 |
| XCH，ACC=5、M=9 | 逐句赋值 ACC=9、M=9；旧状态算新状态 ACC=9、M=5 |
| LDA 不更新 Z | 同一程序输出 0，1029 步 |
| JZ 前显式 ADD 0 | 两种约定都输出 42 |
| 200 + 100 | ACC=44，C=1，跳到进位分支 |
| STA 后紧跟 HLT，写回延后一拍 | 立即停机 M=0；先提交再停机 M=42 |
| 漏写 HLT，内存为 0 | 操作码 0 即 HLT，停机 |
| 漏写 HLT，内存为 0xFF | fault：停在 0x04；nop：跑满 1000 步，OUT 8 次 |
| 单元测试 | 6 个通过 |

## 五、误差、限制与不能推出的结论

- 这是教学用的指令集，不对应任何真实处理器；真实 ISA 的标志位规则以各自手册为准。
- 「同一时钟沿」用不可变状态和纯函数模拟，没有模拟门电路的传播延迟；延后一拍的写回只模拟了一个挂起的写。
- 步数上限 1000 是实验设定，用来代表「不会自己停下来」。
