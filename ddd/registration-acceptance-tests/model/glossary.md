# 词汇表：报名上下文

| 术语 | 含义 | 不是什么 | 代码名 |
|---|---|---|---|
| 场次 | 一个活动在某个时间、地点的一次举办，有固定容量 | 不是活动本身；一个活动可以有多个场次 | Session |
| 参会人 | 在报名上下文里占位置的人 | 不是会员中心的「会员」，也不是计费上下文的「付款人」 | AttendeeId |
| 报名 | 参会人占用一个场次名额的动作 | 不是营销的「线索」 | register |
| 候补 | 名额已满时排队等待的位置 | 不是报名失败 | CandidateWaitlisted |
| 递补 | 有人取消后，候补第一位拿到名额 | 不是重新报名 | CandidatePromoted |
| 取消 | 参会人放弃已占的位置 | 不是活动被取消 | cancel |
| 截止 | 场次不再接受新报名 | 不影响已有报名的取消 | closeRegistration |
| 应收 | 计费上下文里一笔待收的钱，由策略生成 | 不是支付单 | CreateCharge |
