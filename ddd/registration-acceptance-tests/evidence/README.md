# 证据说明

全部由 `make evidence`（即 `scripts/verify.sh evidence`）生成。

| 文件 | 内容 |
|---|---|
| `test-results-draft.txt` | 初稿模型的用例结果 |
| `test-results.txt` | 修订模型的用例结果 |
| `traceability.tsv` | 规则—用例、术语—代码的对应 |
| `maven-test-draft.log`、`maven-test.log` | Maven 输出 |
| `environment.txt` | 运行环境 |

规范化：Maven 输出中的仓库路径替换为 `/workspace`。
